# KH Fab

Kh International-ийн лист төмрийн **nesting (өрөлт)** ба **bending (нугалалт)** програм. Windows дээр суудаг, интернэтгүй ажилладаг, шинэ хувилбар гарахад автоматаар шинэчлэгддэг.

## Суулгах
`KH-Fab-Setup-x.y.z.exe`-г ажиллуулна. Анх суулгахад Windows «Windows protected your PC» гэж анхааруулж магадгүй (кодын гарын үсэггүй тул) — **More info → Run anyway** дарна.

## Автомат шинэчлэл (GitHub Releases)
1. GitHub дээр **public** `kh-fab` репозитор үүсгээд энэ хавтасны агуулгыг (node_modules, dist-ээс бусад) оруулна.
2. `package.json`-ийн `version`-ийг нэмээд (жишээ нь `1.0.1`) `v1.0.1` tag push хийнэ:
   ```
   git tag v1.0.1
   git push origin v1.0.1
   ```
3. GitHub Actions (`.github/workflows/release.yml`) Windows суулгагчийг бүтээж Releases-д тавина.
4. Releases-ээс татсан суулгагч өөрийн репогийн хаягийг агуулдаг тул тохиргоо хэрэггүй. Өмнө нь өөр суулгагчаар суулгасан бол програм дотор **Nesting → Тохиргоо → Програм** хэсэгт GitHub эзэмшигчийн нэрийг оруулна.

Програм нээгдэх бүрт (мөн 4 цаг тутам) шинэ хувилбар шалгаж, далд татаж аваад дээд талд «бэлэн — дарж суулгана» гэж харуулна.

## Хөгжүүлэлт
- Эх код: `src/` (`shell.html` + JS модулиуд). `npm run build-app` → `app/index.html` (офлайн) болон `web/` хувилбарыг үүсгэнэ.
- Туршиж ажиллуулах: `npm start`
- Суулгагч бүтээх: `npm run dist`

## Хувилбарын түүх
### 1.5.0
- **Kh International нэр, лого**: програмын толгой, цонхны гарчиг, бүх PDF / хэвлэх баримтад компанийн лого. «Ажил → Ажлууд» хэсгийн доор лого солих боломжтой.
- **Ажил — 5 таб**: Ерөнхий · Scope·хуваарь (хамрах хүрээ, үе шат + Гантт, эрсдэл, тоног) · Үнийн санал (материал, consumable, ажиллах хүч, тоног/үйлчилгээ, бусад, хаягдал, тээвэр, ашиг, НӨАТ; захиалагчийн санал ба дотоод тооцоо) · Явц·зардал (үе шатны гүйцэтгэл, зарлагын бүртгэл, төсөв ба бодит, CPI/SPI, таамаг ашиг) · Акт·өөрчлөлт.
- **Үзлэг · заавар модуль**: 8 тоног/автомашины өдөр тутмын үзлэгийн хуудас (компанийн загвараар), нэмэлт 4 (лазер, токарь, гагнуур, forklift), сарын багц, цахим үзлэг + түүх, засвар/жолооны бүртгэл, ажлын байрны заавар.
- Бүх баримт **PDF** болон **шууд хэвлэх** товчтой.

### 1.4.0
- **Англи / Монгол хэл**: дээд талын **МН / EN** товчоор дарж сольдог. Цонх, хүснэгт, зураг дээрх бичиг, мессеж, PDF тайлан, CSV, iLogic дүрэм англиар гарна. Сонголт хадгалагдана.
- **Night / Day горим**: «☾ Night» товчоор харанхуй, «☀ Day» товчоор цагаан өнгөнд шилжинэ.
- Утасны дэлгэцэнд үр дүнгийн табууд гүйлгэгддэг болсон.

### 1.3.1
- **Өрөлтийн хувилбарууд**: тооцоолол олсон өөр өөр листийн хэмжээ, өрөх аргатай шилдэг 12 хүртэлх хувилбарыг жагсааж (лист, ашиглалт, материал, өртөг, шинэ үлдэгдэл), дурын нэгийг сонгоно.

### 1.3.0
- **«Мэдээлэл · сан» модуль**: уул уурхайн 30 техникийн (Sandvik, Epiroc, Caterpillar, Komatsu, Hitachi, Liebherr, БелАЗ) үзүүлэлт эх сурвалжтайгаа, шанагын 13 төрөл, багтаамжийн тооцоо. Техникээс шанагыг багтаамжаар нь шууд үүсгэнэ.
- **Параметрт загварууд**: pegboard, ажлын ширээ, сандал, тавиур, L бэхэлгээ, суурь хавтан — хавтгай эд анги (нугалаа, боолтны нүх тааруулсан), 3D харагдац, иж бүрдэл.
- **Inventor iLogic** параметрт дүрэм (Part ба Assembly), **STEP** (B-rep) ба **STL** экспорт, шанагын 3D угсралт.
- **STEP/IGES импорт**: 3D-ээс хавтгай хавтангуудыг зузаантай нь салгаж Nesting-д оруулна.
- **Миний сан**: татсан DXF/SVG/STEP файлуудаа ангилал, эх сурвалж, лицензийн тэмдэглэлтэй хадгална.

### 1.2.0
- **Зургаас парт**: гар зураг, фото, сканаас контур таньж нум болгоно. Цаасны 4 буланг заахад хазайлтыг засч, цаасны хэмжээгээр масштаблана. Шугамаар болон дүүргэж зурсан дүрс аль алиныг уншина.
- **AI хэмжээ уншигч** (сонголтоор, өөрийн Anthropic API key): гараар бичсэн хэмжээсийг уншиж масштаб тогтоож, дугуй нүхийг Ø хэмжээнд яг тааруулна.

### 1.1.0
- **Хурдны жишиг хүснэгт**: материал (хар ган, Hardox, зэвэрдэггүй, хөнгөн цагаан) × зузаан × лазерын кВт. Чадал хүрэхгүй зузааныг анхааруулна. Өөрийн хүснэгт рүү хуулж засна.
- **Дулаан тараах дараалал** (Hardox, зузаан хавтан), **гинжин зүсэлт**, **мөргөлдөөнөөс зайлсхийх** (тойрох эсвэл толгой өргөх).
- **Төвөөс орох зам / спираль** дугуй нүхэнд, **нүхний хаягдал хуваах**, **араг яс хэрчих**, нимгэн листэд **fly-cut**. DXF (SLUG, SKELETON, CHAIN давхарга) болон G-code хоёуланд.
- **Параметрт шанага үүсгэгч**: хэмжээ оруулахад хажуу, ороох, ир, дээд, чих, элэгдлийн тууз, хажуугийн ирийг гаргаж, багтаамж, жинг тооцоод иж бүрдэл болгоно.
- **Галзуу (3 булт)**: дэлгэмэл урт, төгсгөлийн нэмэгдэл, дээд булны суулт, хүч, шалгах шаблон.
- **BOM импорт** Excel/CSV-ээс (DXF файлуудтай нэрээр холбоно).
- **Ажлын самбар**: хугацааны зураг, хэтэрсэн ажил, төсөв ба бодит, гэрээний үнэ ба ашиг.

### 1.0.2
- **Ажил · захиалга** модуль: `KH-2026-001` хэлбэрийн ажлын дугаар, захиалагч, хугацаа, төлөв, түүх.
- **Иж бүрдэл** (жишээ нь шанага): нэг бүтээгдэхүүний бүх эд ангийг хадгалж, ажилд «× тоо» гэж оруулна.
- **ISO 9001 ул мөр**: материалын гэрчилгээ (хайлалтын дугаар) бүртгэл, лист бүрийн зүсэлтийн бүртгэл, ажлын карт PDF.
- **Төлөвлөсөн ба бодит зардал** харьцуулалт.
- **Лазер тэмдэглэгээ**: парт бүр дээр ажил ба партын дугаар (MARK давхарга).
- **QR шошго** парт болон үлдэгдэлд. Үлдэгдэл дугаартай (`R-0001`), байршилтай.
- **Микро холбоос**, мөргөлтөөс сэргийлэх «туузаар» зүсэх дараалал, тасарсан партын дээгүүр явалтын тоо.
- Зузаанаас жижиг нүх, хэт богино элементийн анхааруулга.
- **G-code (NC)** гаралт, кодуудыг тохируулах боломжтой.
